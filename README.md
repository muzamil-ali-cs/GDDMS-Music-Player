## 📌 About the Project

**GDDMS Music Player** is a web-based music player designed to provide a smooth and interactive music-listening experience.

The project allows users to import music directly from their local folders, browse their songs, view album covers, and control playback through a modern interface.

Unlike a basic music player, this project also demonstrates the practical implementation of **Data Structures and Algorithms (DSA)** in a real-world application.

## ✨ Features

- 🎧 Play and pause music.
- ⏭️ Next and previous track controls.
- 📂 Import multiple songs from local folders.
- 🎨 Display album covers and song information.
- 📃 Interactive Song List drawer.
- 🔊 Volume control.
- ⏱️ Music progress bar and playback duration.
- 🕒 Recently Played history.
- 🔍 Song searching.
- 📱 Responsive user interface.
- ⚡ Custom Data Structures and Algorithms implementation.

## 🧠 Data Structures & Algorithms

One of the main objectives of this project is to demonstrate how DSA can be used in practical software development.

| Data Structure / Algorithm | Implementation |
|---|---|
| Doubly Linked List | Manages playlist navigation, next and previous songs. |
| Queue | Manages the internal Up Next sequence. |
| HashMap | Provides an efficient song search index. |
| Merge Sort | Organizes songs through sorting. |
| Stack | Maintains Recently Played history. |

These structures are implemented using JavaScript rather than relying entirely on built-in data structures.

## ⚙️ Requirements

Before running this project, make sure you have:

- Node.js installed (LTS version recommended).
- npm (included with Node.js).
- Git installed.
- Visual Studio Code or another code editor.
- A modern web browser.
- Local audio files for testing.

Check your Node.js and npm installation:

```bash
node -v
npm -v
git --version
```

## 🚀 Installation & Setup

Follow these steps to run GDDMS Music Player on your computer.

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/muzamil-ali-cs/GDDMS-Music-Player.git
```

### 2. Navigate to the Project Folder

```bash
cd GDDMS-Music-Player
```

### 3. Install Dependencies

```bash
npm install
```

This command installs all required project dependencies.

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Your Browser

Vite will display a local URL in the terminal, usually:

```text
http://localhost:5173/
```

Open that URL in your browser to use the music player.

## 🏗️ Build for Production

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🎼 How to Use

1. Open GDDMS Music Player in your browser.
2. Navigate to **Import Music**.
3. Select your local music folder.
4. Import your songs.
5. Open the Song List to browse available tracks.
6. Select a song to start playback.
7. Use the player controls to manage your listening experience.
8. Visit Recently Played to view your listening history.

**Note:** Music files are selected from your local device. The project does not provide an online music streaming service.
